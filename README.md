# P5XTool
> [!NOTE]
> This tool only works with Windows builds of the game.

This repo contains P5XTool and a few dependency libraries. P5XTool is a tool that can help view the files of Persona5: The Phantom X as well as a few utilities such as:
 - Accurate Dialog Sprite Exports
 - Model Previews
 - Bundle Extraction (with recursive dependencies)
 - Bundle Viewer
 - Config Data Export
 - Lua Script Export
